# Road-safety comparisons under different denominators

Study 19 of the independent research program asks which state comparisons change when the same recorded fatalities are divided by population, licensed drivers or vehicle miles traveled. These denominators answer different questions. A location-based fatality count per resident is not the death risk of that state's residents, and motor-vehicle miles do not measure pedestrian or cyclist travel exposure.

We will retain all 51 states/DC, three separate report-year snapshots, exact all-fatality counts and feasible ranges implied by rounded road-user shares. No synthetic exact subgroup count will be substituted for a rounded percentage.
